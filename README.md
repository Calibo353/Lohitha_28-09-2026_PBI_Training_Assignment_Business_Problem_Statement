# PBI_Training_Assignment_Business_Problem_Statement

## 📊 Power BI Sales Intelligence Dashboard

This project is a **Power BI Sales Intelligence Dashboard** developed as part of the PBI Training Assignment.

The dashboard provides an interactive view of business performance across sales, profitability, products, customers, salespeople, locations, time trends, and budget performance.

---

## 🎯 Project Objective

The objective of this project is to transform sales and business data into an interactive Power BI solution that helps management understand:

- Overall business performance
- Year-over-year sales performance
- Product performance
- Customer performance
- Salesperson performance
- Geographic performance
- Profitability
- Budget vs Actual performance
- Time-based sales trends

---

The assignment dataset contains information from:

## 🏗️ Data Model

The Power BI report uses a structured data model containing:

- `Fact_Sales`
- `Product_Data`
- `Customer_Data`
- `Location_Data`
- `Salespeople_Data`
- `Date_Table`
- Budget-related tables

A dedicated Date Table is used for time-based analysis and time-intelligence calculations.
